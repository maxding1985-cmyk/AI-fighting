# AI Tank Duel MVP

一个“赛前用策略规则驱动坦克自动对战”的第一版原型。

## 当前已实现

- 单机双坦克自动对战
- Canvas 像素风战斗画面
- JSON 规则校验与解释执行
- 本地策略生成器（用于先替代真实 AI 接口）
- 子弹、冷却、障碍物、命中、超时平局
- Node 房间服务：创建房间、加入房间、确认策略、再来一局
- 双浏览器通过 SSE 同步同一场服务端权威战斗
- SSE 心跳、断线宽限、浏览器自动重连和快照恢复
- 房间邀请链接：`?room=房间码` 可直接预填加入房间
- 同一标签页刷新后自动恢复玩家身份，其他标签页可手动恢复上次身份
- 结果页、战斗日志和基础在线状态展示
- 基础测试覆盖战斗引擎、规则校验和房间管理

## 运行

```bash
npm start
```

然后打开：

```txt
http://localhost:5173
```

## 测试

```bash
npm test
```
